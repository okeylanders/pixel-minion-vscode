## Changes Summary

### Features

- **Recraft Vector SVG integration** — new `OpenRouterImageSVGClient` (TextClient adapter) + `SVGOrchestrator.selectClient` dispatch routes Recraft model ids through the image-output API path, decoding `data:image/svg+xml;base64,…` payloads back into raw SVG markup so the existing SVG tab UI works unchanged.
- **Catalog expansion (SVG):** Recraft V4.1 Pro Vector (default, ⭐), Recraft V4 Vector, Claude Opus 4.7 (⭐), GPT-5.4, Gemini Flash 3.5.
- **Catalog expansion (Image):** Recraft V4.1 Pro / V4 Pro / V4 / V3 raster, xAI Grok Imagine (Image Quality).
- **Refine UX:** disabled with an explanatory placeholder when a Recraft vector model is selected (Recraft regenerates instead of iterating).
- **Default SVG model** switched from `openai/gpt-5.3-codex` → `recraft/recraft-v4.1-pro-vector`.

### Fixes

- **Seedream 4.5 modality bug** — was sending `["image","text"]` and 404'ing; added `bytedance-seed/` (plus `recraft/` and `x-ai/`) to the image-only branch in `OpenRouterImageClient.getModalitiesForModel`.
- **`extractMimeType` regex** — hardened to accept `image/svg+xml` (the `+` doesn't match `\w`).
- **Catalog correctness:**
  - `anthropic/claude-opus-4` displayName was "Claude Opus 4.5" — fixed to "Claude Opus 4".
  - `gemini-3-flash-preview` pricing was $0.15/$0.60, corrected to $0.50/$3.00.
  - Removed two dead-endpoint entries: `gemini-2.5-flash-image-preview` and `gemini-3-pro-preview`.

### Breaking Changes

None. The default-model change is forward-only (existing user settings preserved).
