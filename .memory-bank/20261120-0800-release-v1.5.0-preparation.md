# Pixel Minion v1.5.0 release preparation

Prepared November 20, 2026 on `release/v1.5.0`. The latest GitHub release was v1.4.0. The three subsequent commits contain the model refresh and merge plus the previous release's icon optimization and publication record.

- SVG adds GPT-6.2 Astra, GPT-6.2 Sol, and Gemini 4 Neon. The GPT-6.2 requests omit temperature.
- Single Shot adds MAI-Image 2.7 Flash and Seedream 5.5. Endpoint fixtures and mocked transport tests cover both.
- This minor release preserves saved model IDs and settings. It changes the manifest and lockfile root version, README, and both changelogs. Dependency resolutions are identical to v1.4.0.

## Validation

- Jest and coverage both passed 63 suites and 1,298 tests. Coverage was 87.00% statements, 82.55% branches, 79.40% functions, and 87.32% lines.
- All three TypeScript configurations passed. Webpack completed with bundle-size warnings.
- The full public npm audit reported 37 affected development packages, including one critical, 24 high, nine moderate, and three low. The production audit reported zero affected packages. The configured registry returned HTTP 404 for audit. The current moderate-and-higher package list matches the prior [dependency disposition](../docs/release-audit-v1.4.0.md). Handlebars is reached through the ts-jest config initializer, which is outside the release workflow. Generation tests cover the application routes. They do not establish the security of the development tools. Dependency upgrades remain deferred.
- Focused review found no release blocker in catalog routing, default model selection, or the GPT-6.2 request change. The release carries the existing missing-license packaging exception.

The owner confirmed v1.5.0 and authorized release and publication without an installed-VSIX smoke test. Package verification, merge, tag, GitHub release, and Marketplace publication follow this checkpoint.
