## Notes

### Architectural decisions

- **Parallel client over branching**: created `OpenRouterImageSVGClient` rather than adding image-call logic inside `OpenRouterDynamicTextClient`, keeping each client's API call shape coherent. Dispatch decision lives in `SVGOrchestrator.selectClient`.
- **Prefix-based dispatch**: `model.startsWith('recraft/')` is intentionally simple and lives in two places (modality dispatch in `OpenRouterImageClient`, vector-client dispatch in `SVGOrchestrator`). Acceptable until a third axis emerges; documented in review action plan.
- **Refine gated for Recraft**: rather than attempting to encode prior SVG as `image_url` in a follow-up turn (requires touching `SVGConversationManager` extensively), we disable Refine and direct users to start a new generation. Followup item — full multi-turn Recraft support — captured in review action plan.
